# StudyFlow

האפליקציה שלי 

הרעיון של האפליקציה שלי הוא לעזור לתלמידים לארגן את הלימודים שלהם ולתכנן את המשימות שלהם לבית הספר.

מסכים

מסך פתיחה

זה המסך הראשון שנפתח. הוא מציג את הלוגו של StudyFlow עם אנימציה. אחרי 3 שניות הוא עובר למסך הכניסה.

מסך כניסה

כאן המשתמש יכול להכניס שם משתמש וסיסמה. אם אחד השדות ריק או שהפרטים לא נכונים, מופיעה הודעה. יש גם כפתור להרשמה.

מסך הרשמה

כאן המשתמש יכול ליצור חשבון על ידי הכנסת שם משתמש וסיסמה פעמיים. הסיסמה חייבת להכיל לפחות 6 תווים ושתי הסיסמאות חייבות להיות זהות. אחרי ההרשמה המשתמש חוזר למסך הכניסה.
